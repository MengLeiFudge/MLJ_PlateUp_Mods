本模组通过自建服务器中转 PlateUp 的联机对局数据，需要服务器管理员运行配套中转服务，玩家安装本模组及 Harmony 后，在“设置 → 游戏中转”填写服务器地址，再按原来的 Steam 方式邀请或加入房间。


【服务器管理员：部署中转服务】

1. 准备服务器
使用玩家可访问的服务器；现有部署方案面向 Linux x64。服务器只负责转发数据，不需要安装 PlateUp 或 Steam。

2. 获取并编译配套服务
公开源码仓库：
https://github.com/MengLeiFudge/MLJ_PlateUp_Mods

完整源码 ZIP 下载：
https://github.com/MengLeiFudge/MLJ_PlateUp_Mods/archive/refs/heads/main.zip

下载并解压完整仓库，在编译电脑安装项目所需的 .NET SDK，按 mods/PlateUpRelay/README.md 的“源码与构建”发布服务端。服务端项目位于 mods/PlateUpRelay/src/Server，并引用同一模组下的 src/Shared，请保留完整目录结构及根目录 NuGet.Config。

3. 部署程序并开放端口
将发布得到的文件部署到服务器，启动 PlateUpRelay.Server；仓库提供 mods/PlateUpRelay/deploy/plateup-relay.service，可通过 systemd 管理服务。
在云安全组和系统防火墙中放行程序监听的 UDP 端口，默认 UDP 27841。更换端口时，程序的监听端口与防火墙规则需对应；使用端口映射时也需转发 UDP。
服务器必须运行配套中转程序；仅开放端口或运行其他程序，无法提供本模组所需的中转功能。

4. 将连接地址提供给玩家
把玩家可访问的公网 IPv4 和端口告知房主及其他玩家，游玩期间保持中转服务运行。
同一局的所有玩家共用这个中转服务，不需要每人部署一台服务器。中转服务不代替房主运行游戏，房主仍须在线。


【玩家：安装模组并连接】

1. 安装前置与模组
房主和所有参与玩家均需订阅本模组及 Harmony（创意工坊 ID：2898033283），使用相同版本的模组，然后重启游戏。

Tip：工坊加载限制与手动安装（Windows）
官方因工坊恶意模组事件暂时停止加载新上传的模组；带有此限制的游戏版本会跳过工坊 ID 大于 3820868888 的条目。本模组的工坊 ID 为 3823021451，受此限制时，即使已订阅并下载，也不会通过工坊加载。请按以下步骤安装到本地 Mods 目录：

① 退出游戏，等待 Steam 完成本模组的订阅下载。
② 打开对应 Steam 库下的 steamapps\workshop\content\1599600\3823021451，将 PlateUpRelay.dll、LiteNetLib.dll 和 LiteNetLib-LICENSE.txt 复制出来。
③ 在游戏所在 Steam 库下创建 steamapps\common\PlateUp\PlateUp\Mods\PlateUpRelay，将上述文件直接放入该文件夹。可在 Steam 中右键 PlateUp → 属性 → 已安装文件 → 浏览，进入其中的 PlateUp 文件夹后找到或新建 Mods。
④ 保留 Harmony 订阅，重启游戏，再继续下面的第 2 步。房主和其他玩家都需要完成此操作，并使用相同版本。

本地副本不会随工坊订阅自动更新，更新时需退出游戏并手动替换文件。官方恢复工坊加载后，请移走本地副本再使用订阅版本，避免重复加载。
官方说明：《Workshop Incident - October 2026》，见 https://steamcommunity.com/app/1599600/allnews/


2. 填写中转地址
向服务器管理员取得 IP 和端口，在主菜单或没有其他玩家的房间中打开“设置 → 游戏中转”，点击“中转地址”输入或粘贴，按回车确认。
默认端口 UDP 27841 可只填写 IPv4；使用其他端口时填写 IP:端口。地址栏不支持域名或 IPv6。
点击“保存并启用”。房主和其他玩家必须填写同一个中转服务的 IP 和端口；玩家无需下载源码或部署服务端。

3. 正常邀请或加入房间
按原来的 Steam 好友邀请和加入房间的方式联机。入房后，模组自动完成身份确认和中转连接。
右下角版本文字上方显示 Server / Room 延迟，设置菜单可查看详细连接阶段。等待身份确认时，房主也须安装并开启模组。服务器连通且房主中转就绪后，才能开始经中转同步对局。
房主仍负责运行游戏逻辑，游玩期间须保持在线；Steam 房间与初始化通道需要正常可用。

4. 修改设置或关闭中转
请先离开多人房间，再进入“设置 → 游戏中转”修改地址或点击“关闭中转，使用原联机”。返回游戏不会关闭中转。


【兼容性、效果相关】

• 只面向 Steam 版联机，暂不支持 Photon 跨平台联机。
• 只转发游戏对局数据，不影响电脑的其他网络流量。
• 中转效果取决于玩家和房主到服务器的线路质量、丢包及带宽，不保证降低延迟，也不能解决电脑性能导致的掉帧。
• 右下角显示 Server … ms, Room … ms：Server 是本机到服务器的往返延迟；Room 是经中转到房主的实测往返。未入房、尚无样本或样本过期时显示 - ms；本机房主显示 Room 0 ms。详细连接状态可在设置菜单查看。
• 房间延迟测量需要配套的新版服务端。升级时先更新服务端，再让同一房间的所有玩家统一更新模组；手动安装的本地文件需要手动替换。
